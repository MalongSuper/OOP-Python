# Object-Oriented Programming with Python

This repository is a **collection of basic Python code examples demonstrating Object-Oriented Programming (OOP)** using classes and objects.

The examples focus on understanding how classes are defined and used in Python, along with the fundamental concepts that form the foundation of OOP.

## Contents

The repository covers:

* Classes and objects
* Constructors and methods
* Attributes and instance variables
* Class and static methods
* Inheritance
* Encapsulation
* Polymorphism
* Abstraction
* Basic relationships between classes
* Small examples and exercises using OOP concepts

### The Four Pillars of OOP

* **Encapsulation** — Bundling data and the methods that operate on it within a class.
* **Abstraction** — Hiding unnecessary implementation details and exposing only what is needed.
* **Inheritance** — Creating new classes based on existing classes to reuse and extend functionality.
* **Polymorphism** — Allowing different classes or objects to provide their own implementations of the same interface or method.

## Notes

* This repository is intentionally **lightweight** and contains basic examples rather than large OOP-based applications.
* The code is primarily intended for **learning and demonstrating how classes and OOP concepts work in Python**.
* More examples may be added over time.
